Core of the T Agent gate: capability vocabulary, scope matching, policies, decisions and attestation tiers.

This crate is the executable counterpart of the Lean specification in lean/TAgentSpec. The two are kept in step by the conformance tests in crates/tagent-cli/tests/conformance.rs, which feed the same random cases to this crate and to the compiled Lean model and compare the answers. Bounded properties of this crate are also model-checked with Kani (see src/kani_harness.rs).

The crate has no unsafe code, never panics on any input (all slicing and arithmetic is checked by Clippy lints), and performs no I/O.
