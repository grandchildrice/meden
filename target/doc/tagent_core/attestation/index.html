Attestations: the only thing the admission gate ever reads.

A verifier plugin (Lean 4, h5i, Verus/PDD Kit, a test runner, a scanner) turns an artifact and a property into an attestation. The gate classifies attestations into three tiers (TAgentSpec.Attestation):

  • Tier::Verified: result is proved and the TCB contains nothing outside LEAN_ONLY_TCB. Accepted mechanically.
  • Tier::VerifiedWithTcb: result is proved but the TCB names another prover (Verus, Z3, …). Accepted only when the property mapping for that verifier backend has been approved by a human; the TCB is surfaced.
  • Tier::NotVerified: tested, scanned or failed. Never confers verified; usable as supporting evidence only.
