Frontend for Agent Skills packages (SKILL.md + scripts).

Reads the frontmatter used by Claude Code, pi, Hermes and OpenClaw (the agentskills.io specification), including OpenClaw’s metadata.openclaw.requires block, scans bundled scripts for effects and reports the capabilities the skill would need.

The static scan over-approximates: a skill the scan says needs shell.exec and net.egress must either be granted those or be rejected. The patterns are a stand-in for real typing of script languages, not a security boundary; the boundary is the policy and the attestation gate.
